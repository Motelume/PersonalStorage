# PersonalStorage 0.10.0b1

这是供个人、同学和朋友使用的Windows x64测试版。项目以MIT许可公开在GitHub，不进行宣传推广；未经使用者确认，不标记为1.0。

新增本地全文与LSA语义相似度检索、嵌套AND/OR/NOT条件、旧式偏好字段编辑、收件箱任务/用途投递、管理状态恢复向导、原资料校验备份及恢复到新目录、经过预览确认的任务目录状态变更、通用规则包升级界面、AI规则候选和目录关联建议。

新增旧版DOC/PPT/XLS、RTF、HTML、OpenDocument、EPUB、邮件及字幕提取；提供可选本地音视频转写、公式LaTeX、手写增强及表格行列重建。可选组件首次准备需要下载依赖和模型，识别不上传原件。复杂手写、公式及合并单元格结果仍需核对。

发布物包含便携ZIP、按用户安装的Setup.exe和SHA-256校验文件。安装和升级将程序与资料分开，旧版本保留以供回退；卸载保留资料、规则、索引、密钥和备份。当前测试包未配置可信代码签名证书，签名接口已提供。

移动硬盘管理、多机器协作继续保留接口，本版不实施。详见[测试版使用与边界](beta-guide.md)。
