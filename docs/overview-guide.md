# 目录总览：关系图与目录树

0.7.0新增“目录总览”，网页版与Windows桌面版共用同一页面。默认显示悬浮文件夹卡片组成的关系图，可切换为传统目录树。浏览的是当前资料库，外部下载或微信目录仍在收件箱管理中登记。

## 关系图

点击卡片查看信息，点击加号展开下一层，双击目录进入分支聚焦；“返回全库”恢复根视图。拖动画布平移，滚轮缩放，底部工具可缩放及适应画布，小地图可回到整体。拖动卡片只改变画布布局，不移动磁盘资料。“自动排布”清除手动偏移，恢复当前可见节点的自动布局。

默认不显示文件。勾选“显示文件”后，已展开目录中的文件也作为卡片出现。选中文件时可复制完整路径、显示所在目录；本页不运行文件。目录和文件信息来自当前文件系统，显示位置不代表已通过AI分类审核。

卡片有约2至3像素、不同节奏的轻微漂浮，连线随卡片一起更新。悬停或选中的节点暂停，拖动、平移或编辑关联时暂停整体动效；切走页面、窗口不可见时停止动画循环。“漂浮动效”可关闭，并尊重系统“减少动态效果”。

## 实线与手动关联

- 实线来自真实父子目录结构，不能通过拖线改变。
- 虚线是用户明确添加的关联，可写“参考资料”“成果复用”“相关任务”等说明和备注。

选择节点后点击“添加关联”，再选择另一个节点；也可先搜索目标并定位，再填写关系说明。编辑窗口列出已经加载过的节点，可调整两端位置和备注。关联支持文件夹或文件，不能关联自身。

点击虚线可查看两端完整路径、编辑说明或移除关联；顶部“关联”按钮可查看全部记录，包括已失效的端点。移除关联只删除管理记录，不删除任何资料。

端点被资源管理器移动、改名、删除或替换后，关联显示“需重新定位”。先在图中展开或搜索新的节点，再编辑关联并明确选择新端点；不凭同名自动绑定。项目、比赛与通用资料的分类原则不因手动关联而改变。

## 目录树与搜索

“目录树”使用相同的目录与关联数据，保留图中选中的节点。展开按钮读取下一层，右侧显示详情与手动关联。目录树与详情各自滚动。

名称搜索匹配文件名或相对路径，可选择仅目录或目录与文件；不读取正文、不调用AI。点击结果会展开必要的父级并定位，文件结果会启用显示文件。搜索可以在切换页面后继续，完成后在侧边栏显示未读提示；可点击“停止搜索”，也可提交新关键词停止旧搜索。

目录浏览与名称搜索使用独立的只读通道，不排在AI审核或归档队列后。浏览与搜索不会移动文件或生成可执行归档计划。

## 保存与第一版边界

视图选择、动效开关、展开状态、选中位置、布局偏移和画布位置保存在当前资料库对应的本机状态中。手动关联保存在同一本机SQLite数据库的`graph_links`表中，包含端点的相对路径与文件系统身份；不写入原资料，不进入Git或程序分发包。管理数据库快照包含这些状态，仍不包含原资料正文。

首次进入只读取根节点与顶层目录，之后按需展开。单个目录每批200项，可继续加载；当前画布/目录树最多绘制240个节点，较大分支适合双击聚焦，搜索定位优先保留目标所在分支。名称搜索每次最多返回500项、读取100000个目录项，达到上限时会提示细化关键词。技术目录如`.git`、`node_modules`和虚拟环境默认不进入浏览或搜索；管理目录可浏览，但搜索不递归其内部。

本页没有实际移动、删除或重命名原资料的操作；关联生成由用户手动发起。0.10测试版已在目录总览接入正文/本地语义检索与按钮触发的AI关联候选；OCR已实现。离线硬盘图谱继续暂缓。
