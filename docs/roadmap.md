# 后续规划

更新日期：2026-10-28。

前两项已在0.10.0b3实现，具体入口和边界见[使用说明](workflows-guide.md)。规划文本不是自动执行授权，1.0仍须用户另行确认。

## 1. 根据内容自动重命名文件

状态：0.10.0b3已实现，默认预览并明确确认后执行。

目标：对名称含义不明确、难以检索的文件，读取内容后生成有依据的名称；现有名称已经有明确意义时，保留原名。

预期流程与规则：

- 先结合原名、目录上下文和提取内容判断名称是否有明确意义。不能仅因名称短、包含数字或不符合某种格式就改名；课程编号、项目代号等可能本身有意义。
- 仅对确需改名的文件生成建议。优先复用本地文字提取、OCR和已有缓存；需要AI时，沿用启用、发送范围确认和用量限制。
- 名称使用内容中可证实的主题、用途等信息，不编造作者、日期、版本或归属。证据不足时保持原名，交给用户判断。
- 提供“原名 → 建议名”、改名依据及保留原名的选择，允许人工编辑和排除单项。首版默认预览并确认后执行；无人确认的自动执行策略另行设计。
- 保留扩展名和文件内容，检查非法字符、保留名称、路径长度及同名冲突；不覆盖已有文件，不借改名去重或移动到其他目录。
- 记录改名前后路径与内容指纹，协调索引、人工归属、审核记录和相关缓存的路径更新；支持经校验的撤销，冲突或原件变化时停止对应项。
- 本需求仅针对文件名称；不扩展为自动重命名任务目录或资料包内部结构。

验收要点：含义明确的名称保持不变；含糊名称可以根据内容提出可解释建议；内容不足时不改名；同名冲突和中断不导致覆盖、丢失或记录错位；改名前后文件字节一致。

## 2. 批量人工分类与批量指导AI分类

状态：0.10.0b3已实现，默认预览并明确确认后执行。

目标：处理多个同类型文件时，共用一次人工决策或补充说明，减少逐个选择目录、重复输入的操作。

预期交互与规则：

- 复用现有勾选和执行能力，在收件箱、审核与待办中扩展多选、已选数量和已选清单；明确仅处理选中项，筛选变化不悄悄扩大范围。
- 人工分类：一次为多个选中文件选择目标目录、任务、用途和分类依据，形成逐文件预览；执行前允许修改或排除个别文件。
- 人工指导AI：一次输入共同背景或性质说明，应用到明确选中的文件；同时保留单个文件的补充说明。
- AI结合共同说明和每个文件自身的内容分别判断，可以给出不同目标。同一批次不强制放入相同目录；证据不足项继续待确认。
- 调用前展示文件数量、发送范围及批次限制，沿用现有隐私确认和每日用量限制；不将本次共同说明自动发布为长期分类规则。
- 结果逐项展示建议、依据、冲突和待确认状态，支持“只采用已核对项”；继续遵守人工锁定、外部收件箱复制/转移方式及执行前校验。
- 执行中允许切换页面，提供进度、安全停止和侧边栏完成提示。分别记录成功、失败、跳过项，只重试重新核对后的未完成项，不重复执行已成功操作。
- 保留逐文件操作记录和现有可撤销范围；不扩大当前撤销或删除权限。

验收要点：同类文件可通过一次目标选择或一次共同说明批量处理；不同性质文件能够分别建议或保留待办；排除项与未选项不受影响；部分失败可明确定位并重试；每项结果可追溯。

## 继续暂缓

- 移动硬盘管理：保留接口，待实际需求明确后再实施。
- 多机器协作：保留接口，暂不开展跨机状态同步与共同整理。

## 当前边界

常规整理仍保留原名；用户明确确认后，可由独立改名流程改变含糊文件名。首次实现支持库内普通独立资料，外部原件先归档后处理副本；不改变资料包内部结构。本轮不开展安装包重新发布、代码签名、硬盘管理或多机协作。
