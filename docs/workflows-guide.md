# 内容辅助命名与批量分类

适用于0.10.0b3测试版，入口仍在原有七个页面内。

## 内容辅助重命名

选择收件箱或待办中的文件，点击右侧“根据内容建议文件名”。只对“新建文档”“无标题”等含糊名称建议改名；课程编号、项目代号及正常标题保留。优先从本地提取文字或OCR缓存寻找标题，机构名、章节序号、敏感字段不作为标题，证据不足保留原名。

可以编辑建议名和依据，再检查“原名 → 新名”预览，明确确认后执行。保留扩展名、内容和修改时间；同名冲突、保留名称、非法字符、文件或规则变化时停止。AI帮助需先补充说明、预览发送范围并确认，沿用正文开关、每日上限和Token记录；AI不能执行改名。

通过列表上方“改名记录”检查撤销；原名未被占用且文件内容未变化时才恢复。持久化日志记录内容指纹，中断恢复仅核对已发生的改名。索引、审核绑定、AI位置缓存、说明和关联同步更新或失效；正文索引可重新生成。

支持库内独立文档、图片及音视频，不改目录、程序、依赖或已登记资料包内部成员。外部收件箱原件保持原样，先归档再对副本改名。存在待清理原件时先核对转移记录；副本改名后继续跳过已导入复制来源，不借旧名称重复导入或自动清理原件。

## 批量人工分类

列表新增独立的“批量选择”复选框，支持全选当前筛选结果和清除选择。工具栏显示已选数量，可跨筛选保留选择。点击“批量指定归属”，共用一次目标目录和分类依据。

预览逐项显示源、目标和复制/转移方式；无法生成计划的项目单独报错。可取消勾选任一计划，只执行已核对项目，分别显示成功与失败。失败项保留供重新核对，不自动重放成功项。每次最多100项，不同时选资料包及内部成员；本次说明不发布为长期规则。

## 批量指导AI分类

选择文件，填写共同背景及可选的单项说明。已有人工锁定归属需逐项明确选择本次重新判断。发送前展示文件、说明、摘录、模型、批数及剩余额度，确认后才发送。

每次最多50项，按AI管理的批次上限拆分；重新判断人工锁定项单独绑定确认。AI逐文件独立判断，可给出不同目标，不强行统一归类。失败批次显示原因，重试需重新预览发送范围。

返回后原件不移动。在审核与待办勾选拟采用的建议，点击“预览所选AI归属”，再次逐项核对并确认执行。未确定项继续补充说明，所有原有来源方式与完整性校验继续适用。

## 真实资料评估

规则管理 → 运行设置 → 分类质量与速度评估，支持只读评估明确标签及查看最近报告。记录标签来源、规则独立命中率、待确认比例、提取范围限制、错误与耗时；不借既有归属充当预测，不调用AI或移动原件。

历史助手核对标签仅作为注明来源的参考集，不等同独立人工真值；小样本不能外推全库准确率。真实文件名、标签和评估明细留在本机，不进入GitHub。
