# 规则可视化管理

0.9.0在网页与桌面共用的“规则管理”中提供五个页签：分类约定、自动分类规则、任务绑定、试跑与版本、运行设置。原有后台授权、快照与OCR设置在运行设置中，DeepSeek连接仍在AI管理。

## 分类约定与执行条件

分类约定展示固定顶层职责、细分结构和判定边界。编号、顶层名称、固定目录骨架与保护约束不可修改；用途、边界和细分建议可保存为本地草稿。“恢复此类通用描述”只改草稿描述，不重建目录或替换私人任务。

长期偏好使用条目记录说明、范围、例外和依据，发布到有效配置的`explicit_preferences`，供在线AI读取。原有私人Markdown在界面中只读对照，需人工确认后迁入；不会自动变成脚本条件。原有非结构化偏好保留原格式，不强制转换。

自动规则只执行明确条件：`name`、`text`、`kind`、`context.task_id`、`context.purpose`。`kind`仅为文件或文件夹；正文包括原生文字和OCR。任务、用途必须由调用方明确提供，常规收件箱扫描没有这两个上下文字段，不能据此期待自动命中。CLI的`plan --task`和样本试跑可显式提供任务上下文；界面单次选择归属继续走原有人工预览。

一条规则内所有条件同时满足；“或”用多条规则表达。可用等于、包含、属于文字列表和高级正则。正则最长256字符，隔离进程最多运行2秒，超时进入待确认，试跑和正式分类共用实现，不增加联网依赖。

数字更小的决策层级先采用。同层命中规则若指向不同目录，进入待确认；列表顺序不表示优先级。明确任务上下文优先验证任务是否唯一、目录是否存在、是否已完成或归档。最终移动仍经过原来的范围、完整包、人工归属、内容变化和同名检查。

## 从修改到生效

1. 编辑后点击“保存草稿”。草稿保存在当前资料库对应的本机状态中，重启保留，尚不改变有效配置。
2. 选择“检查草稿”，修正无效条件、重复标识、缺失目标等问题。
3. 在“试跑与版本”输入模拟样本，或从库内、已登记外部收件箱选择1–10个文件/资料包。可补充明确任务和用途。试跑复用现有提取和OCR，展示现行版与草稿的命中路径、冲突、来源和警告。
4. 点击“查看差异并发布”，核对字段变化、样本结果和未评估范围，再确认发布。改动执行规则或任务绑定必须先完成样本试跑；只改管理名称或备注不需要重新试跑。
5. 有效配置变化后旧文件计划、AI发送预览及基于旧规则的复核缓存不再适用，持续后台授权撤销。重新授权后才可继续后台整理。发布不会自动扫描全库、调用AI或移动原文件。

试跑与发布进入既有后台队列，切换页面不中断，完成后在规则管理图标提示。编辑区、列表与解释区分别滚动。试跑可更新提取缓存和管理摘要，不新增待办、人工归属或导入标记。

真实样本以完整性指纹绑定；样本内容或OCR设置变化后需要重新试跑。每次保存新草稿都会清除上一草稿的试跑凭据。页面中的完整文字与命中轨迹只在本次会话保留，历史仅保存受控试跑摘要和版本绑定。

## 任务、外部修改与回退

任务绑定只登记已有目录，不创建、改名或归档文件夹。登记状态与“（已完成）/（已归档）”后缀不一致时显示检查警告；不推断移动后的新位置。已有离线、暂存状态保留，其工作流暂缓。

浏览器窗口、桌面窗口和外部编辑器同时改规则时，草稿修订号与有效配置指纹会阻止旧内容覆盖。外部修订可通过“比较外部修订”三方合并；同字段双方修改时需明确选择保留哪一方。未解决时完整保留原草稿。

历史独立于七天活动记录，保留最近50个发布版本；首次纳管和外部修订也会登记。回退先把历史规则建立为新草稿，按当前目录重新检查、试跑和发布；不会撤销已发生的文件操作，也不会恢复旧后台授权。

## 文件与恢复边界

`_整理规则/分类配置.json`是唯一有效配置。管理数据库保存草稿、显示名称、备注、停用规则和发布历史；发布时仅将启用规则编译到原有`executable_rules`，不依赖执行器忽略未知的启停字段。

发布前备份配置与管理版本，原子替换配置，并记录跨JSON/SQLite的提交阶段。异常重启按有效配置指纹修复匹配的管理状态；发现第三个外部修订时保留它并提示比较。未完成的文件操作会阻止发布。

发布后生成`_整理规则/规则阅读版.md`，标明版本、指纹、分类约定、执行条件和保护范围，供人或其他AI读取；它不是第二个有效配置。位置已有非生成文件时保留原文件，显示阅读版未完成，可在排查后重试。原有私人Markdown始终保留。

私人规则、阅读版、实际任务与路径、试跑信息、历史和备份都不进入公开仓库。程序仅分发通用模板。

## 后续接口

`RuleManager`提供读取、保存草稿、校验、模拟、发布预览、确认发布、历史建草稿和外部修订合并。HTTP为本机会话鉴权适配，前端不直接写配置。

保留通用包版本、稳定规则ID、配置指纹、预期版本发布和位置解析边界。移动硬盘管理与多机器协作本轮暂缓：不增加硬盘迁移、联网同步、账号、共享数据库或自动合并任务。现有目录和数据字段继续保留。

0.10测试版补充嵌套AND/OR/NOT、旧式偏好字段编辑、收件箱明确任务/用途投递、任务状态目录名预览变更及AI规则候选。原文中0.9的单层条件与只读兼容格式边界由[测试版说明](beta-guide.md)更新。
