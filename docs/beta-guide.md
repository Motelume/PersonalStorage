# 0.10 测试版使用与边界

应用版本为`0.10.0b1`。`release-policy.json`中的`user_approved_1_0`保持false；构建和发布门禁拒绝未经确认的1.0。公开范围为GitHub public项目，供个人和朋友分享使用，采用MIT许可。

## 检索与规则

目录总览保留关系图和目录树，在原页面增加正文检索。点击“更新本地正文索引”后按批次只读提取，未变化内容复用缓存；默认每批500文件，可继续更新。管理目录、硬盘管理及技术依赖目录不索引。索引存于本机`search.sqlite3`，不随源码或安装包公开，不包含原件备份。

全文检索支持中文短词和原文片段；本地语义相似度使用TF-IDF与LSA，最多最近1500篇、2500个词项。它不调用API，不保证理解所有同义词；相似度分数不是分类准确率。索引不实时监控修改，更新后再查看新的正文结果。

自动规则可从简单条件升级到嵌套AND/OR/NOT，最多6层、64个叶条件。未提供的字段采用未知值，NOT不会把“缺失”变成匹配。新增`extension`字段；名称和扩展名不能单独证明课程或任务归属。试跑与执行共用判断逻辑，旧规则保持原样。

旧式结构化偏好可按原字段编辑，保留布尔、数字、数组和文字的类型，不强制转换。更改仍先保存草稿、检查、试跑和发布。正文中出现的命令只作为资料内容，不执行。

## 投递、任务状态与AI建议

收件箱可为本次手动扫描选择明确任务和用途。任务绑定需唯一、目录存在并处于本机进行中状态。改变上下文会清除旧的选择与建议，要求重新扫描；预览与执行绑定同一上下文。普通持续后台不继承界面上的临时投递用途。

任务绑定页可预览“进行中/已完成/已归档”的文件夹名变化，明确确认后只修改任务目录后缀，并更新任务、执行目标和已登记路径。内部文件名称与字节保持原样，旧计划失效、后台授权撤销。存在冲突或未完成文件操作时阻止。中断按事先登记的路径和指纹恢复，不猜测新位置。

AI规则候选和目录关联均由按钮发起，先预览发送范围，再调用DeepSeek。AI不直接发布规则或操作文件；规则候选以停用状态加入草稿，需人工启用、试跑并发布；关联逐条确认。它们共用每日用量限制和Token记录。模型不能发明候选范围外的路径。

## 备份与恢复

规则管理的运行设置提供备份恢复向导。管理快照保存数据库及配套规则文本，不包含原资料；恢复前检查库/卷身份、数据库完整性和规则指纹，先保存恢复前副本。可明确选择是否恢复配套有效配置。恢复后后台授权撤销，需核对文件操作记录。中断恢复回到恢复前管理状态。

原资料备份是独立的校验复制流程，先展示数量、大小、空间和新建备份目录，再确认执行。文件变化或空间不足时停止并标记未完成。恢复原资料只允许写入尚不存在的新目录，逐文件核对SHA-256，保留当前资料。不把未完成备份当完整来源。

备份包含私人信息，应自行保管。代码仓库、管理快照、原资料备份分别维护。通用规则包更新另有比较入口，继续保留私人任务、执行条件和本地改动。

## 扩展提取与本地识别

只读解析增加DOC/PPT/XLS、RTF/HTML、ODT/ODS/ODP、EPUB、EML、SRT/VTT及文本类文件，不打开Office应用、不运行宏或附件。旧版二进制Office、加密、损坏和复杂嵌入对象可能无法完整提取，此时保留警告并待确认。

运行设置中的增强识别工具提供：

| 模式 | 实现 | 使用条件 |
|---|---|---|
| 表格行列 | 本地OCR坐标聚类 | 内置；复杂合并单元格、跨页结构需核对 |
| 手写增强 | RapidOCR PP-OCRv5模型 | 首次准备下载并校验模型；不保证任意手写准确 |
| 音视频转写 | faster-whisper 1.2.1、CPU int8、Whisper small | 按需安装本地Python环境；本次最多30分钟/16000字，结果标明是否完整 |
| 公式LaTeX | pix2tex 0.1.4 | 按需安装；本地环境和模型占用较大，输出需要核对 |

可选音频/公式组件需要本机Python 3.11–3.13，主桌面程序本身不依赖用户安装Python。只在明确“准备组件”时访问官方包仓库和模型仓库；识别工作进程禁止联网。组件目录可在界面指定，不随应用更新删除。音频解码固定兼容的PyAV 15.1.0，避免新版接口变化。

识别先展示结果，人工核对后可采用为分类提取文字；按内容指纹存入本机派生缓存，下次规则扫描可复用。不会向原图/PDF写入文字层、修改文件或自动归档。用于识别的输入必须从受控库内或已登记收件箱选择。

上游说明：[faster-whisper](https://github.com/SYSTRAN/faster-whisper)、[LaTeX-OCR](https://github.com/lukas-blecher/LaTeX-OCR)、[RapidOCR模型与许可](https://rapidai.github.io/RapidOCRDocs/main/en/model_list/)、[xlrd](https://xlrd.readthedocs.io/en/latest/)、[Microsoft Office格式规范](https://learn.microsoft.com/en-us/openspecs/office_file_formats/)。模型和依赖的许可不因本项目MIT许可而改变。

## 任务、安装与更新

任务栏可请求停止后续处理；文件操作在当前安全边界结束，API调用可能需等到返回或超时。自有解析/识别辅助进程采用可取消的Windows作业对象，只结束本程序创建的子进程。扫描、索引和位置复核可经明确按钮重新发起并复用已完成缓存；文件移动、删除和规则发布不会在重启后自动重放。

同库桌面重复启动会定位已有窗口；网页版使用独占端口，识别已有同库服务并给出地址，防止旧版和新版同时占同一端口。关闭仍有任务的桌面窗口会提示安全停止范围。

便携版应保留完整目录。安装包按用户安装独立版本目录，默认桌面快捷方式不创建；保留旧版本并更新已有资料库入口。卸载只处理安装清单中未修改的程序文件，保留资料、本机状态、修改过的程序旁文件、旧便携版和卸载工具。WebView2检测失败时给出[微软官方下载入口](https://developer.microsoft.com/microsoft-edge/webview2/)。

应用中的更新检查只访问本项目GitHub测试版，下载后校验SHA-256并备份当前管理状态，安装仍需明确操作。回退前检查旧程序是否支持当前规则并备份，之后退出当前程序从现有入口重开。含新条件的规则不能直接交给不兼容旧版。

## 验收与真实准确率

质量面板按人工提供的标签计算准确率、可归档精确率、召回率、待确认比例和耗时。不从预测结果反推正确答案，不将合成样本指标宣传为真实全库准确率。私有标注与结果留在本机。

自动化验收覆盖原有功能、嵌套条件、增量索引、恢复、取消、空间不足、源变化、路径越界、安装载荷校验、保留资料卸载及打包自检。公开测试用合成数据。尚未人工标注的真实资料集、不同Windows版本/硬件和长期运行仍需实际试用；测试版不替代原资料备份。

签名脚本支持用户提供的真实代码签名证书，不创建虚假可信签名。当前测试版未配置此证书。发布流水线只创建prerelease；1.0需要后续明确确认。
