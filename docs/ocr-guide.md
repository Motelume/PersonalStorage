# 本地OCR识别

0.8.0将本地文字识别接入现有规则优先的整理流程。支持PNG、JPG/JPEG、WEBP、BMP、TIFF/TIF、GIF及扫描版PDF。动画/多页图片按帧处理，PDF按页处理；原文件、格式、内容、名称和修改时间保持不变，不向原件添加文字层或生成旁边的同名文件。

## 分类流程

能直接取得文字的PDF页面优先直接提取；无文字的页面、以及含图片且仅有少量页码/标题文字的页面，再进行本地OCR。文字页和扫描页混合的PDF逐页选择方法。图片先按EXIF方向调整识别副本，识别使用中文/英文印刷体模型。

识别正文进入现有`text`条件规则。规则能确定归属时生成预览建议；启用智能分类时，只把仍未确定的资料及必要摘录交给DeepSeek。OCR不自动移动文件，不自动发布规则，也不触发全库AI复核。OCR模型分数用于过滤识别行，不代表分类准确率。

## 设置与查看

“规则管理 → 运行设置”中的“本地OCR识别”可启停识别、设置最大页/帧数、最低识别行分数及单文件超时，执行本机合成图片自检或清空缓存。默认最多前5页/帧、行分数0.85、工作进程最长60秒，可分别调整到1–20页、0.50–0.99及15–180秒。

详情页展示文字来源：直接提取、本地OCR或两者混合，并显示缓存复用、各页方法、字符量和识别分数。低分行不作为分类正文；超过页数、字符预算或发生失败时明确标记读取不完整，不能理解为未读部分无文字。可点击“重新读取（忽略缓存）”重读当前选定文件。

停用OCR后，原本可直接提取文字的PDF继续工作；图片或扫描页回到名称、上下文、AI或人工判断流程。加密PDF、损坏文件、无法识别文字或超时均保留原位，不尝试密码、不运行嵌入程序。

## 本地运行与缓存

桌面包包含固定的RapidOCR 3.4.2 / PP-OCRv4模型、ONNX Runtime CPU引擎及PDFium渲染组件。三份模型按公开固定SHA-256校验，并显式指定本地模型和系统字体；识别工作进程禁止网络连接和DNS解析。运行时不下载模型，不读取DeepSeek密钥，不调用付费API。缺组件或校验不符时显示不可用提示。

缓存位于`%LOCALAPPDATA%/PersonalStorage/ocr/cache.sqlite3`，与资料目录和公开仓库分离。按文件内容SHA-256、类型、识别配置、引擎协议和缓存代际绑定，缓存最多2000条、约32MiB结果正文。移动/改名或仅改变时间时可复用内容结果；内容、配置或识别协议变化时重新读取。不同摘录长度复用同一份最多16000字的结果，发给AI仍遵守原有4000字预算。

OCR处理的是本机生成的不可变临时副本，结束后再次核对原件内容；读取中变化的结果不用于分类或缓存。清缓存会使其他窗口中的扫描缓存失效，正在识别的旧结果不能回填旧代际。失败和超时不作为永久成功缓存。损坏缓存可通过“清空识别缓存”重建，原损坏数据库另存到同一私有状态目录。

缓存保存的是提取文字，不是原文件备份，也不跟随便携包或Git分发。OCR设置属于当前Windows用户的本机设置，多个资料库共用；`PERSONALSTORAGE_HOME`可在测试中隔离全部识别状态。

## 资源边界与能力范围

只读输入上限128MiB，单张图像最多2400万像素，识别副本最长边2400像素。页/帧数、字符量与超时均有限制，未覆盖部分会标记。每个应用进程只同时运行一个识别/解析OCR工作进程，避免扫描线程同时启动多套模型。OCR所需内容哈希只针对图片/PDF候选；普通文件建议扫描继续使用元数据缓存，真正归档前后仍完整验证。

第一版面向清晰的中文/英文印刷文字，不承诺手写、数学公式、复杂表格、流程图或版式结构还原。低质量结果应结合人工说明继续判断；不会把模型分数当作人工核验结论。

## 源码安装与构建

```powershell
python -m pip install -r requirements-ocr.txt
```

或安装项目的`ocr`/`desktop`可选依赖。完整桌面构建使用`requirements-desktop.txt`，已经引用OCR依赖。构建先校验本地模型，再收集权重、配置、运行库和第三方许可；不收集个人缓存或资料。打包版自检包含真实合成图片离线识别及设置面板。

单元测试中的真实中英文图片、原生/扫描混合PDF，以及`tools/frontend_ocr_smoke.cjs`均使用临时合成资料。Windows CI安装同一OCR依赖后执行真实识别测试；不使用用户原资料或真实DeepSeek调用。

实现依据：[固定RapidOCR版本](https://pypi.org/project/rapidocr/3.4.2/)、[本地模型参数](https://rapidai.github.io/RapidOCRDocs/main/install_usage/rapidocr/parameters/)、[PDFium只读渲染与文字接口](https://pypdfium2.readthedocs.io/en/stable/python_api.html)。
