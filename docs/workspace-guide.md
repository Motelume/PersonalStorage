# 页面任务、操作记录与扫描

适用于0.5.0的网页版和Windows桌面版，两种入口共用这些行为。

## 页面与后台任务

扫描、AI等待、移动预览、执行、导出等任务可在切换页面后继续。来源页面的状态和结果独立保存，不会在返回时覆盖另一页的列表、选中项或弹出错误页面。侧边栏运行圆点代表处理中；任务结束后显示未读结果数量，失败结果用红色标记。打开对应页面即清除未读提示，并可查看结果。

每页同一时间处理一项任务；其他页可以提交任务并进入队列。本机工作队列按顺序执行，避免两个动作同时改动同一资料。切页不会取消排队或运行任务；关闭应用仍会等待已提交工作收尾，重启后不会自动重放移动指令。

## 最近七天的操作记录

操作记录包括扫描、AI审核、导入导出、预览及实际移动。任务日志保存到当前资料库的本机SQLite状态中，关闭软件不会清空。默认展示最近七天，每页100条，可按文件路径或任务名称搜索、筛选状态。尚未完成的文件恢复记录继续显示。

左侧记录列表与右侧详情分别滚动。滚动到列表底部再选择记录时，详情仍位于右侧可视区域；详情自身很长时可单独滚动。

七天限制适用于界面的任务活动。旧的完整移动审计、恢复事件和索引不会因此删除，以免破坏核对、恢复与撤销依据。任务日志不保存API密钥、请求体、提示词或资料正文。

## 快速扫描与移动校验

扫描只生成待确认的归属建议：安全枚举资料、对整个候选批次共享一次稳定观察窗口、读取必要特征。相同文件元数据和规则下可复用本次服务缓存。大型目录不再因为出现在列表中就被完整哈希，也不再为扫描写两份大型可执行清单。

点击移动预览后才对选定资料生成完整SHA-256清单、重新判断归属并检查目标；执行前后仍核对完整内容。元数据或规则变化会要求重新扫描。缓存不会绕过完整性校验。

本地12个小文件的合成对比测试：旧扫描约12.10秒，新扫描约1.02秒，约11.8倍；两者归属建议相同。该数字来自合成数据，实际速度受数量、格式、目录深度和磁盘速度影响。

## 当前哪些地方使用AI

| 入口 | 是否调用模型 |
|---|---|
| 智能扫描 | 规则先分类，只对未确定项自动调用AI |
| 补充性质或用途后让AI分类 | 确认发送后调用AI，目标明确时直接预览 |
| AI管理中的全库位置复核 | 仅由按钮启动，已合理且未变化的结果复用 |
| 原有单项或批量审核 | 手动确认后调用AI |
| 测试连接 | 只查询模型列表，不做推理 |
| 初次打开页面的扫描、规则执行、移动、复制、撤销、恢复、后台轮询 | 不调用AI |

移动和外部归档始终要确认计划。外部来源可分别选择复制保留原件或校验后转移删除原件；已有来源默认保留原件。转移失败保留副本并在记录中提示清理状态。全库复核不自动移动资料。完整说明、来源管理与调用预算见[AI分类与位置复核](ai-guide.md)。
