# DeepSeek AI管理

AI管理页提供密钥保存与移除、模型选择、启用开关、连接测试、正文摘录开关、每批数量和每日审核上限，以及最近调用状态和Token记录。

默认模型`deepseek-flash`，按[DeepSeek官方接口说明](https://api-docs.deepseek.com/)调用。可选择`deepseek-v4-pro`。连接测试查询模型列表；审核使用JSON输出和非思考模式，单次最多4096输出Token。网络超时60秒，仅对限流和部分服务器错误最多重试一次。

## 审核流程

1. 在AI管理保存本机密钥，启用审核并测试连接。页面不回显已保存的密钥。
2. 从收件箱或待办选择资料。可审核当前一项，或在配置的数量上限内批量审核。
3. 查看发送预览：选定文件名、当前归属、候选目录及可选文字摘录。每项最多4000字；不发送完整原文件。资料包只提取有限成员信息，不拆包执行。
4. 点击“发送这几项至DeepSeek”后才访问API。AI返回确认、需要补充信息或归属建议，文件不移动。
5. 建议出现在待办详情。选择“采用AI建议并预览”，核对目标后再执行。这个人工决定只影响当前资料。

AI不发布长期规则，不执行shell，不直接移动文件，不修改人工锁定归属。不支持的格式和证据不足项保持待确认。普通后台轮询不会触发AI。

## 凭据、用量与失败

凭据库位于`%LOCALAPPDATA%/PersonalStorage/credentials.sqlite3`，仅保存DPAPI密文；密钥不在程序目录、资料目录和Git仓库。复制桌面应用不会带走密钥，换电脑需重新输入。

每批默认最多5项，每日默认30批；页面可调整。记录最近200批的实际Token，并展示最近30批。计数是逻辑审核批次，不是金额预算；失败批次也计入每日限制，避免反复重试。没有返回用量时不估算Token或费用。

发送前与返回后检查规则、文件版本、对象身份和归属决定版本。未知目录、重复或缺失对象、无效JSON、截断响应等不会成为有效移动指令。不可用密钥、余额不足、限流和网络失败会给出受控错误，可在修复后重新预览。

测试使用合成资料和模拟提供方。连接真实API时应先用不含私人信息的小样本验证，不以全库资料作为测试输入。
